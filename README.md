# Малярия

Интерактивная математическая лаборатория из коллекции «Полный перебор».

[Открыть игру](https://zintsovasmile-web.github.io/malyariya/)

## Правила
Двое по очереди красят вершины дерева. Нельзя красить уже окрашенную вершину и вершины, соседние с окрашенными. Проигрывает участник, который не может сделать ход.

## Как пользоваться
1. Выберите число вершин (2–9) и дерево. Всего доступно 94 неизоморфных дерева.
2. По очереди нажимайте на доступные вершины. Можно отменить ход или начать заново.
3. После завершения нажмите «Сохранить результат»: партия попадёт в журнал с цветным рисунком, победителем и последовательностью ходов.
4. Записывайте наблюдения в исследовательский дневник. Черновики и сохранённые записи хранятся автоматически в этом браузере.
5. Экспортируйте все данные в JSON для резервной копии и переноса; CSV содержит журнал партий. Импорт JSON заменяет текущие записи и партии.

Данные хранятся локально на устройстве, а не в GitHub. Незавершённая партия после перезагрузки не восстанавливается; сохраните законченный результат в журнал.

## Публикация
GitHub Pages: ветка `main`, папка `/ (root)`. Откройте публичную ссылку в современном браузере. Для локального использования откройте `index.html`.

Исходник: `malyariya (3).html`, опубликован как `index.html` без изменения игровой логики и оформления. Шрифты загружаются из Google Fonts, при отсутствии сети используются запасные шрифты.
